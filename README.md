# 记账本 · money-ledger

> 一个跑在终端里的小记账程序：**记一笔 → 存进文件 → 下次打开还在 → 按类别看"钱花在哪了"**。

## 为什么写它

我是大一新生，这是我写的第一个完整程序（在 AI 当教练的情况下，自己一行行敲出来的，还很稚嫩）。写它的原因有三个：

1. **练手** —— 真正提升自己写代码的能力；
2. **留个脚印** —— 把自己的成果摆出来，记录一下自己走过的路；
3. **真能用** —— 说不定我真用上这个记账本了。

这是我踏出的第一步。

## 功能
- [x] 记一笔：`物品 金额 类别`（空格分隔，输 `q` 结束）
- [x] **数据持久化**：存进 `money.json`，关掉程序再打开旧账还在
- [x] 清单 + 汇总：笔数 / 总额 / 平均
- [x] **按类别汇总**：每一类花了多少、几笔
- [x] **导出报表**：把"按类别"那张表写进 `报表.txt`（每次运行重写）
- [ ] 按类别排序（v1.2 计划）

## 快速开始（3 步）
```bash
git clone https://github.com/18fantasy/money-ledger.git
cd money-ledger
python ledger.py
```
> 需要 **Python 3.8+**；**不需要安装任何第三方库**（只用了标准库 `json`）。

## 用到的技术（说人话 + 对应岗位关键词）
| 技术 | 在哪 | 干什么 |
|---|---|---|
| **文件持久化** | `json.load` / `json.dump` | 数据落在磁盘上，程序重启还在（对应 JD 里的"文件/数据处理"） |
| **列表 + 字典** | `records` | 一个列表装字典：`[{"item":…, "money":…, "category":…}]` |
| **字典当计数器** | `result[键] = result.get(键, 0) + 值` | 按类别汇总（读旧值 → 加 → 写回） |
| **函数 + `return`** | `show()` / `sum_by_category()` / `count_by_category()` | 把逻辑拆开，各自交回结果 |
| **兼容旧数据** | `.get("category", "未分类")` | 早期数据没有 `category` 字段也不会崩 |
| **导出报表** | `with open("报表.txt", "w")` + `f.write` | 把结果落成文件，别人能直接拿去用 |
