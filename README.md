# 记账本 · money-ledger

> 一个跑在终端里的小记账程序：**记一笔 → 存进数据库 → 下次打开还在 → 按类别看"钱花在哪了"**。

## 功能
- [x] 记一笔：`物品 金额 类别`（空格分隔，输 `q` 结束）
- [x] **数据持久化**：存进 `money.db`（SQLite），关掉程序再打开旧账还在
- [x] 清单 + 汇总：笔数 / 总额 / 平均
- [x] **按类别汇总**：每一类花了多少、几笔
- [x] **导出报表**：把"按类别"那张表写进 `报表.txt`（每次运行重写）
- [x] **按类别排序**：金额从多到少（v1.2）
- [x] **SQLite 数据库**：账本存进 `money.db`（v2.0a）
- [x] **每笔账带日期**：新记的自动记今天；早期没有日期的老数据**显示 `—`，不编造**（v2.0b）
- [x] **只看某个月**：`python ledger.py --month 2026-09`（v2.0c）

## 快速开始（3 步）
```bash
git clone https://github.com/18fantasy/money-ledger.git
cd money-ledger
python ledger.py
```
> 需要 **Python 3.8+**；**不需要安装任何第三方库**（只用标准库 `sqlite3` 和 `datetime`）。

> ⚠️ **Windows 用户注意（本人实测踩过一次）**：如果直接在 `cmd` 黑窗口里跑，中文可能显示成乱码（`��������Ʒ`）——这是 Windows 默认代码页（936/GBK）和 Python 输出编码不一致，**不是程序出错**。
> 解法：先执行一次 `set PYTHONUTF8=1`，再运行 `python ledger.py`（在 PyCharm 里跑没有这个问题）。

## 样例

**账本数据不进仓库**：第一次运行时程序会自动建库，敲几笔就长这样（下面是我自己跑出来的）：

```
1. 早餐 8 吃饭 2026-10-14
2. 地铁 4 交通 2026-10-14
3. 奶茶 15 吃饭 2026-10-14
4. 苹果 12 水果 2026-10-14
共4笔 总额39 平均9.75
--- 按类别 ---（按金额从多到少）
吃饭: 23 (2 笔)
水果: 12 (1 笔)
交通: 4 (1 笔)
```

> 每笔末尾是**它自己记下的日期**；要是早期没有日期的老账，它会老实显示 `—`，不编造。

## 用到的技术

| 技术 | 在哪 | 干什么 |
|---|---|---|
| **SQLite 持久化** | `sqlite3` + `CREATE TABLE IF NOT EXISTS` / `SELECT` / `INSERT` / `commit` / `close` | 数据按行读写；**关掉程序再打开，旧账还在**（v2.0a） |
| **日期** | `datetime.date.today()` → `str()` → 存进 `date` 列 | 新记的一笔自动带今天日期；老数据 `NULL` → 显示 `—`（v2.0b） |
| **`?` 占位符** | `VALUES (?, ?, ?, ?)` | 值用参数传进去，不用拼字符串（拼字符串容易被注入/被引号坑） |
| **列表 + 字典** | `records` | 一个列表装字典：`[{"item":…, "money":…, "category":…, "date":…}]` |
| **字典当计数器** | `result[键] = result.get(键, 0) + 值` | 按类别汇总（读旧值 → 加 → 写回） |
| **函数 + `return`** | `show()` / `sum_by_category()` / `count_by_category()` | 把逻辑拆开，各自交回结果 |
| **兼容旧数据** | `.get("category", "未分类")`、`.get("date") or "—"` | 早期数据缺字段也不会崩 |
| **排序** | `sorted(..., key=lambda x: x[1], reverse=True)` | 按金额从多到少 |
| **导出报表** | `with open("报表.txt", "w")` + `f.write` | 把结果落成文件，别人能直接拿去用 |
